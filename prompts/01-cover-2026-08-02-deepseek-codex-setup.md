## 风格规范：dark-atmospheric（电影感深色科技编辑风，强调色变体 A：青色为主）

- 背景：#0A0A0A → #1A1A2E 深色渐变，细网格 + 轻雾
- 排版：粗体无衬线纯白标题；浅灰副文字（#A0AEC0）
- 配色：白 #FFFFFF / 浅灰 #A0AEC0 / 青 #06B6D4 / 紫 #8B5CF6 / 深灰 #2D3748
- 视觉：发光几何硬件、数据流与节点、径向辉光
- Do：高对比、克制的光效、几何精确
- Don't：过曝霓虹、低对比文字、明亮背景

## 视觉主体

画面右侧画一幅抽象的数据连接示意图：三个简洁的几何设备图标（一个终端窗口、
一台桌面显示器、一个代码编辑器括号图形）通过发光的青色数据流线汇聚到中央一个
发光节点（代表 API 服务），节点周围有克制的径向辉光；背景保留细网格与轻雾。
画面左侧保持大面积留白给文字。

所有图形、图标、节点与数据流线上禁止出现任何文字、字母、数字、符号、logo、
水印。
