11 月 16 日，阿里巴巴通义千问团队正式发布新一代旗舰模型 Qwen4-Max。模型基于 Qwen4 系列全新架构，拥有 2.4 万亿主干参数，每个 token 激活 71B 参数，具备原生视觉能力，支持 100 万 token 上下文窗口，定位为可全天候协作的「AI 新同事」。此前，该模型已于 11 月 11 日以预览版（qwen4-max-preview）形式先行上线千问平台。

## 全新稀疏 MoE 架构

Qwen4-Max 围绕 Attention、Residual 与 Embedding 三个方面对稀疏 MoE 架构进行系统升级：

- **GDN + QSA**：每四层中，三层采用 Gated DeltaNet，将历史信息压缩为固定大小的状态；另一层为 Qwen Sparse Attention（QSA），通过轻量级 Indexer 以 block 为粒度选择相关上下文，降低长序列的注意力计算与索引开销。
- **Gated Residual**：将残差流扩展为四条并行分支，通过动态读写门控增强跨层信息传递，提升训练稳定性。
- **N-gram Embedding**：额外引入 328B 参数，根据局部上下文查表提供局部 token 模式表示，以较低的额外计算开销扩展模型容量。

![Qwen4-Max 模型结构示意图](/images/qwen4-max-architecture.png)

官方称，2.4T 参数规模的预训练全程平稳、未出现 loss spike；在知识、代码、问答和 STEM 四类内部评测中，Qwen4-Max-Base 的 BPB（每字节比特数）在五个参评模型中均为最低，较 Qwen3.8-Max-Base 各领域下降约 5–13%，同时每 token 激活参数减少约 25%。

## 评测：对前代显著提升，与前沿模型互有胜负

面向工业与专业场景，千问构建了 Work360 行业基准，涵盖 26 个一级领域、182 个二级子领域和 721 个三级细分领域。最新评测中，Qwen4-Max 得分 52.69，较 Qwen3.8-Max 的 47.74 提升约 10%。

在官方公布的 16 项基准对比中（对手包括 Opus 5.5、GPT-6.1-Sol、GPT-6-Astra 与 Kimi K3.1），Qwen4-Max 在 DeepSWE v1.1（75.7）、Agents' Last Exam v1.1（46.7）、法律智能体基准 HLAB-Vals-1.1（21.3）与 BioMysteryBench（85.0）等长程智能体任务上位居第一；但在 Terminal-Bench 4.0（48.5，低于 Kimi K3.1 的 67.2）、ProgramBench（31.5，低于 Opus 5.5 的 65.0）、Chartography（54.2，低于 GPT-6-Astra 的 71.1）等项目上仍有明显差距。

![Qwen4-Max 在 16 项基准上与前沿模型对比](/images/qwen4-max-benchmarks.png)

效率与成本是另一条主线：在 Work360 上，Xhigh 与 High 两档推理强度的 token 消耗较前代分别减少约 24% 与 35%，在 Terminal-Bench 4.0 上减少约 48% 与 49%。配合 API 定价全面下调、缓存命中价格大幅降低，Work360 单任务平均费用从 26.58 元降至 11.16 元，降幅 58%。

![Qwen4-Max 与前代在不同推理强度下的分数与 token 消耗对比](/images/qwen4-max-efficiency.png)

## 从产线到病房的行业落地

- **汽车制造**：在三丰智能装备、统联精密的实际生产场景中，模型完成产线三维规划、节拍仿真与 PLC 虚拟调试，以及车门总成等零件的建模、刀路生成与仿真核验，在上机前发现过切、少切问题；单个工件加工编程的人工投入从约 475 分钟降至 24 分钟，减少约 95%。
- **金融投研**：可调用 90 个 MCP 工具覆盖 A 股、港美股、债券、基金与衍生品数据，案例中完成沪深 300 股指衍生品的基差与波动率分析，交付可溯源的 Excel 底稿与对齐的 PPT 报告。
- **法律尽调**：将 198 份格式混乱的 IPO 底稿按实质内容重命名并归类为 14 个目录，交叉核验工商、司法等公开信息，最终交付 86 页、6 万余字的尽调报告，覆盖 12 个模块与 14 项法律问题，结论均附底稿引用。
- **危重症医疗**：单次对话通读包含几十份检验单与 1,433 张原始影像的复杂病历，完成指标定位、六天病程时间线梳理与胸部 CT 判读，给出的四条处置建议与主管医生当日医嘱逐条对应。

## 24/7 智能体与科学发现

针对长周期任务，Qwen4-Max 引入 Live Delivery 持续交付机制：先交付可用首版，再逐版扩展内容、提升质量，用户可随每版成果校准方向。配套的 Qwen-Live-Delivery-Plugin 已同步开源。在阿里云真实业务中，模型协同自研求解器 MindOpt 优化调度方案：数据标注场景的模型调用费用平均降低 10.42%，GPU 在线分配的整机空闲容量时长提升 4.62%，CPU 离线重调度的求解速度提升超 14.61 倍。

科学发现方向有两个案例：在深度原理 Mira 平台上，模型连续 48 小时自主运行，从 270 万候选分子中经 4 轮「设计—合成—测试—主动学习」闭环，获得经实验验证的新型冷却液分子；在深势科技 PharmMaster 平台上，围绕阿尔茨海默病相关 NLRP3 靶点完成 454 次工具调用与 3,239 项计算指标评估，优选的候选分子在相对结合自由能评估中，与靶点的名义结合亲和力达到专利起点的约 3.6 倍。

## 安全与可用性

代码安全方面，在 Last Secure Code Bench 上，Qwen4-Max 的函数级功能与安全双通过率从前代的 22.0% 提升至 31.8%，函数、文件、仓库三粒度同时生成安全代码的比例从 8% 提升至 14.7%。官方表示，经内部专家审查，未发现模型具备大规模网络安全风险能力，CBRN 相关风险同样可控且未出现过度拒答。

模型已上线千问 AI 平台，开发者可通过 Token Plan 或 API 接入，并可在千问办公、Qoder CN、千问 App 与 Qwen Studio 中使用。官方同时确认，Max 只是 Qwen4 系列的第一款模型，采用同源技术路线的小尺寸模型将陆续开源。

## 核心总结

- Qwen4-Max 采用 2.4T 主干参数、每 token 激活 71B 的稀疏 MoE 新架构，另有 328B N-gram Embedding，原生视觉，支持 100 万 token 上下文
- Work360 得分 52.69（前代 47.74）；16 项基准上与 Opus 5.5、GPT-6.1、Kimi K3.1 互有胜负，长程智能体任务占优，终端编程与图表理解仍有差距
- Token 消耗大幅下降，叠加 API 降价，Work360 单任务平均费用降低 58%
- 行业落地覆盖汽车制造（编程工时降 95%）、金融投研、法律尽调与危重症医疗
- Live Delivery 持续交付机制与开源插件同步推出，Qwen4 小尺寸模型将陆续开源
